# Tidewing ｜ 潮翼

> **万翼同频，如潮而起。**
> A murmuration-shaped approach to multi-agent collaboration.

Tidewing 是一个研究**多智能体协作框架逻辑**的开源项目：以大模型的「无记忆、上下文有限」两大约束为出发点，构建并持续迭代「**任务层 → 调度层 → 隔离层 → 记忆层 → 兜底层**」五层框架。

当前仓库承载的是项目的**方法论文档**（不是可安装的运行时）；命名 rationale 见 [docs/naming.md](docs/naming.md)。

## 这是什么

- 一份**方法论研究文档**。它回答的问题是：当多个大模型 agent 协作时，框架逻辑应该怎么组织，每层解决什么约束，规则如何由真实失效事件触发并沉淀。
- 框架的所有运维规则（O 系列）均由**真实失效事件**（E 系列）触发，不靠推演——这是本项目区别于一般「最佳实践合集」的核心特征。
- 当前版本：**v14-oss**（开源裁剪版，2026-11-11）。

## 命名

名字来自东营黄河入海口的鸟浪与《逍遥游》：不是一只鸟在飞，是整片潮水长出了翅膀——潮有节律、有方向、不可阻挡，但从不需要一个指挥官。

六个候选名（Tidewing / Murmura / Kunpeng / Skein / Beiming / Fuyao）的逐条拆解与取舍过程见 [docs/naming.md](docs/naming.md)。对内沿用《逍遥游》的意象做模块命名，新人读一遍《逍遥游》，就懂了架构图。

## 运维方法怎么用

如果你只想拿走最实用的部分，直接看框架文档的「运维层」：

1. **落地检查清单**——每次会话结束前的逐项自查；
2. **O 系列规则**——每条规则附带失效事件出处，可直接移植到自己的多 agent 工作流；
3. **O15/O16 并行会话版本纪律**——多会话并行写同一份文档时的「快照-增量-落库」三段式。
