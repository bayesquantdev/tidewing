# naming：从东营鸟浪到鲲鹏，六个英文名的逐条拆解

> 本文转载自项目资料库《naming.md》（宋传，2026-11-11），由检索片段拼合复原；个别表格与过渡段落可能缺失，以资料库原文为准。文末「本仓库实测」为本仓库 2026-11-11 检查结果。

一个多智能体协作平台，最难的不是起名字，是让名字说得清「它凭什么协作」。
所以先定意象，再定词。

## 0. 两个母题为什么能合到一起

多智能体平台要回答的正好是这两件事：一群各自平庸的个体，如何在不设总指挥的前提下产出整体智能；以及单个智能体如何借助共享的上下文、工具与记忆，飞得比自己高。

所以好名字必须同时装得下 **flock（群）** 和 **lift（升）**。

## 1. Tidewing ｜ 潮翼 ★ 推荐

构词：Tide（潮）+ Wing（翼）

出处：东营黄河入海口，鸟群贴着滩涂翻涌，形如潮水；《逍遥游》「其翼若垂天之云」

直译：潮之翼 / 涨潮的翅膀

意境：不是一只鸟在飞，是整片潮水长出了翅膀。潮有节律、有方向、不可阻挡，但从不需要一个指挥官。

平台映射：Tide 是任务流与调度节律，Wing 是单个 agent 的执行力；合起来是「一群 agent 顺着同一股流，各自扇动，整体成浪」。

技术适配：8 字母、双音节、首音节重读，中文用户可读作「潮翼」。CLI 短：`tidewing fly "..."`，缩写 `tw`。作为包名、组织名、域名都够短。

风险：需确认商标与 PyPI 占用（见文末检查清单）。

## 2. Murmura ｜ 群涌

出处：murmuration，英文里专指椋鸟黄昏群飞的「鸟浪」，是这个词的学术叫法；拉丁词根 murmurare（低语、隆隆）

直译：万鸟低鸣 / 群飞之涌

意境：没有指挥，只有「看身边的七只」这一条局部规则，天空却像在呼吸。

平台映射：天然反中心化编排——局部规则 + 全局涌现，正好是 swarm 式多智能体的理论内核。

技术适配：7 字母，结尾 -a 有拉丁的优雅，品牌感强。

风险：murmuration 在开源圈已被用滥（Murmur 哈希、各类 Murmur 应用）；Murmura 拼写在电话里要念两遍。

## 3. Kunpeng ｜ 鲲鹏

出处：「北冥有鱼，其名为鲲。鲲之大，不知其几千里也。化而为鸟，其名为鹏。」

直译：Kun-fish → Peng-bird；西方旧译常作 Leviathan → Roc

意境：一次形变。深潜的巨物，化为垂天之云的飞行者——不是变大，是换了一种存在方式。

平台映射：这是整个项目最强的一句立项宣言：单体大模型（鲲，深潜蓄力）→ 多智能体编队（鹏，展翼协同）。平台做的就是这场「化」。

技术适配：拼音直出，中文社区零解释成本。

风险：英文读者读不出意象；GitHub 上 kunpeng 相关仓库已很多（华为鲲鹏生态），撞名严重，搜索权重会被吃掉。

## 4. Skein ｜ 雁阵

出处：a skein of geese，排成 V 字飞行的雁群；同时也是「一缕纱线」

直译：雁阵 / 一缕

意境：有序编队 + 共享尾流。后雁借前雁的气流可省近七成力气，领飞者会轮换。

平台映射：多智能体协作最精确的隐喻——不是并发，而是编队、借力、轮换领飞。本仓库的拓扑类就叫 Skein。

技术适配：5 字母，CLI 极短（`skein up`），记忆成本低。

风险：与毛线/编织品牌撞词，搜索时噪声大；作为平台主名略窄（只讲了编队，没讲规模）。

## 5. Beiming ｜ 北冥

出处：「北冥有鱼」——冥通溟，无涯之海

直译：Northern Darkness / the Northern Sea

意境：一切的起点是一片看不见底的深水。鸟浪也起于滩涂的暗处——先聚，后起。

平台映射：平台的记忆与上下文层——深、静、不可见，却托起整场起飞。

技术适配：适合做模块名（Beiming = 共享黑板），不适合做产品名：语义太虚，用户不知道它是干什么的。

## 6. Fuyao ｜ 扶摇

出处：「抟扶摇而上者九万里」——扶摇即自下而上的旋风

直译：the whirlwind that lifts

意境：鹏不是硬飞上去的，是等到了那股上升气流。风不来，它就等着。

平台映射：runtime 提供的「上升气流」= 共享上下文 + 工具 + 记忆，agent 借力而起，而不是各自硬算。

技术适配：适合做能力名（Fuyao = 上下文注入器）。

风险：撞福耀玻璃（Fuyao Glass）；拼音对英文用户不友好。

## 结论：一个主名，其余下沉为架构名

平台名：**Tidewing（潮翼）** ✅ 已定

音标：/ˈtaɪdwɪŋ/，双音节，首音节重读

一句话（英）：A murmuration-shaped runtime for multi-agent collaboration.

一句话（中）：万翼同频，如潮而起。

对外只有一个词，说的是「万翼同频，如潮而起」；对内把《逍遥游》拆成模块，让代码自己讲故事（据贡献规范：Peng 领飞、Skein 排阵、Beiming 记忆）。这样命名有个额外好处：新人读一遍《逍遥游》，就懂了架构图。

### 模块名映射（据命名稿与 CONTRIBUTING 整理）

| 名字 | 出处 | 承担的角色 |
|---|---|---|
| Tide | 潮 | 任务流与调度节律 |
| Wing | 翼 | 单个 agent 的执行力 |
| Peng | 鹏 | 领飞（runtime 让群起飞） |
| Skein | 雁阵 | 编队拓扑 |
| Beiming | 北冥 | 共享黑板（记忆层） |
| Fuyao | 扶摇 | 上下文注入器 |

## 英文语境下的可读性评估

横向对比（英文听众听不懂解释时，能还原多少意思）：**结论：在「英文语境能否听懂」这一项上，Tidewing 是本组最优。** 若要把语义锚点再拧紧一格，用仓库名 `tidewing-ai` + 固定副标 a murmuration-shaped runtime for multi-agent collaboration 即可。

## 发布前要做的可用性检查

```bash
# 1) 包名是否被占
pip index versions tidewing 2>/dev/null || echo "PyPI 上大概率可用"
# 2) GitHub 是否已有同名高星仓库
gh search repos tidewing --limit 5
# 3) 商标（重要，尤其打算做产品时）
#    中国：https://wcjs.sbj.cnipa.gov.cn  欧盟：https://euipo.europa.eu
#    美国：https://tmsearch.uspto.gov
# 4) 域名
whois tidewing.dev | head -5
```

**本仓库实测（2026-11-11）**：PyPI `tidewing` 无已发布版本，可用；GitHub API 限流未精确核对，网络搜索未见同名仓库（仅发音相近的 tidings-rss，非撞名），建库时网页端再确认一次。商标与域名尚未检查。

若 `tidewing` 已被占用，备选顺序：`tidewing-ai`（仓库名）→ Murmura → Skein。
